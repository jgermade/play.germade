# Console-Style UI and In-Place Installation

## Topic: Console UI Refactor

- **Status:** In Progress
- **Created:** 2026-07-04 21:20

### Objective
- Redesign the launcher (`src/pages/index.astro`) to mimic a console interface with a horizontal, tilted card carousel.
- Implement in-place installation so downloading/extracting `assets.zip` happens directly within the launcher.
- Provide per-game storage management (ability to clear OPFS data).

### Proposed Changes
1. **Console Carousel UI:**
   - Use CSS transforms (`transform: skew` or `rotateY`) to create a 3D tilted carousel.
   - The selected game will appear flat, scaled up, with its details (title, dev, description) displayed prominently below.
   - Include visual hints for gamepad/keyboard controls (LB/RB for sorting/tabs, A to Play, etc.).
   
2. **In-Place Installation:**
   - Move the `extractAssetsStreaming` logic and `fflate` dependency from `src/pages/game/celeste/index.astro` to the main launcher `src/pages/index.astro`.
   - Update the UI to show a progress bar or status text during extraction.
   
3. **Storage Management:**
   - Add a "Clear Storage" button accessible when a game is selected.
   - The clearing logic will target the OPFS root (or namespace if we implement it) and recursively delete `.ContentExists` and other asset folders.

### Extension (2026-07-04 21:43)
- **Responsive Carousel**: Make the card width responsive and align the selected card to the left instead of center.
- **YouTube Background**: Add a `youtubeId` field to `gamesData` and embed a full-screen, muted, auto-playing YouTube iframe in the background of the launcher that updates based on the selected game. (Replaced with blurred static image backgrounds).
