# Sonic Mania Music Extraction

## Goal
Extract OGG music files from `game-assets/sonic-mania/Data.rsdk` and preload them so background music plays in the WebAssembly build.

- **Status:** In Progress
- **Created:** 2026-07-05 18:45

### Planned Changes
1. **Add extractor script** `scripts/sonic-mania/rsdk_unpack.py` that reads the RSDKv5 `Data.rsdk` archive and writes all contained files to a target directory, preserving internal paths.
2. **Update `scripts/sonic-mania/build-sonic-mania-docker.sh`**:
   - After copying `Data.rsdk` to the work directory, invoke the new extractor to pull out the music files into `$WORK_DIR/MusicExtracted`.
   - Extend the Emscripten `--preload-file` options to also preload `$WORK_DIR/MusicExtracted@/Data/Music` (matching the engine's expected path).
3. **Ensure OGG/Vorbis flags** are present (`-sUSE_OGG=1 -sUSE_VORBIS=1`) – they already are via the existing vendoring steps.
4. **Patch `Settings.ini`** if needed to set `MusicVolume` to a non‑zero default (e.g., 100).
5. **Add a temporary debug log** in the audio initialization code to confirm music files are loaded (optional, can be removed later).

### Verification Plan
- Re‑run the Docker build script.
- Open the game in a browser and check the console for the presence of `/Data/Music/*.ogg` via `FS.analyzePath`.
- Confirm that music plays during the title screen and level load.
