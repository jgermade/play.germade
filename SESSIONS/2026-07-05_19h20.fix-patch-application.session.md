# Sonic Mania Patch Application Fix

## Goal
Ensure that `audio_patch.diff` is correctly applied during the Sonic Mania build process so that debug logs are inserted into `Audio.cpp`.

## Planned Changes
1. **Update build script** (`scripts/sonic-mania/build-sonic-mania-docker.sh`)
   - Apply the patch inside the cloned work directory rather than the repository root.
   - Replace the existing `patch -p1 < "$ROOT_DIR/scripts/sonic-mania/audio_patch.diff"` line with either:
     - `cd "$WORK_DIR" && patch -p1 < "$ROOT_DIR/scripts/sonic-mania/audio_patch.diff"`
       **or**
     - `patch -p1 -d "$WORK_DIR" < "$ROOT_DIR/scripts/sonic-mania/audio_patch.diff"`
   - Ensure the correct flag `-s AUDIO_WORKLET=1` is present in the Emscripten linker options (fix any typo such as `AUDIO_WORKLOT`).

2. **Verify patch format**
   - The diff file uses paths relative to the repository root (`--- a/dependencies/RSDKv5/...`). Applying with `-d "$WORK_DIR"` will locate the target file.
