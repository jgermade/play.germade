## Topic: Sonic 1 Decompilation Integration

- **Status:** In Progress
- **Created:** 2026-07-04 22:45

### Objective
Integrate the Sonic 1 decompilation (WASM) into the launcher.

### Proposed Changes
1. **Engine Setup**:
   - Determine the source repository for the Sonic 1 WebAssembly decompilation (e.g., Rubberduckycooly's Sonic 1/2 decompilation or similar WASM port).
   - Add a build script `scripts/sonic1/build-sonic1.sh` to compile or download the necessary `.wasm`, `.js`, and `.data` files.

2. **Launcher Integration**:
   - Ensure the Sonic 1 entry in `src/data/games.ts` routes to the correct page or loads the WASM engine in the launcher.
   - If using a separate page, create `src/pages/game/sonic-1/index.astro`. If loading in the launcher, adjust the play button logic to mount the Sonic 1 canvas.

3. **Asset Management**:
   - The user will provide the `Data.rsdk` file directly, as the application will be hosted privately.
   - We will configure the engine to fetch or preload this file automatically (e.g. by serving it as a static asset or via our hosted-assets zip system) without requiring the user to manually upload it via the UI.

4. **Gamepad & Controls**:
   - Ensure `patch-gamepad-proxy.mjs` or a similar solution is applied to the Sonic 1 Emscripten output for controller support.
