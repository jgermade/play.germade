# FBNeo integration — Arcade emulator

- **Date:** 2026-07-08 21:52
- **Status:** In Progress

## Goal

Add **FBNeo** (FinalBurn Neo) to the launcher as the Arcade/Neo-Geo emulator core.
FBNeo supports a massive variety of arcade games, including Neo-Geo, CPS1, CPS2, CPS3, etc.

## Research & Plan

FBNeo is typically compiled to WebAssembly via libretro or standalone Emscripten ports.

### Options
1. **RetroArch Web Player (FBNeo core)**: We can use the libretro FBNeo core compiled to WebAssembly. This is standard and reliable, providing wide compatibility.
2. **Standalone FBNeo Emscripten port**: If there's a standalone web port for FBNeo, we could use that instead for less overhead.

### Steps
1. **Identify the Core**: Obtain a WASM build of the FBNeo core (either pre-built libretro core or compile from source).
2. **ROMs Structure**: Set up a `public/roms/neogeo/` folder for the Neo-Geo/Arcade ROMs (.zip files) and BIOS files (`neogeo.zip`).
3. **Frontend Shell**: Create a wrapper page at `public/console/neogeo/` (or arcade) that loads the FBNeo WASM, feeds the selected ROM zip, and handles input/display (perhaps reusing or adapting some libretro web player boilerplate or creating our own).
4. **Launcher Integration**: Update `src/data/games.ts` with the new Neo-Geo core entry so it appears on the main Astro app interface.

## User Review Required

## Implementation Details

We will use the standalone WebAssembly port `OkCyb0rg/fbneo-wasm-port` which is designed specifically for web browsers with a minimalistic shell and ZIP support (perfect for Neo-Geo which requires `neogeo.zip`).
