# Scripts Directory Refactoring

- **Date:** 2026-07-09 01:28
- **Status:** Completed

## Goal
Restructure the `scripts/` directory to separate emulator engine logic (Docker, Makefiles, patching) from console configurations and standalone game wrappers.

## Plan

1. **Create Directory Structure**:
   - `scripts/engines/`: For underlying emulator engine build scripts and Dockerfiles (`jgenesis`, `blastem`, `fbneo`, `rsdkv4`, `rsdkv3`, `rsdkv5`, `smw`, `celeste`).
   - `scripts/consoles/`: For HTML interfaces and ROM scrapers related to specific platforms (`megadrive`, `snes`, `neo-geo`).
   - `scripts/games/`: For standalone decompilation wrappers (`sonic-1`, `sonic-2`, `sonic-cd`, `sonic-mania`, `smario-world`).

2. **Move Files**:
   - Engine components: `build-*-docker.sh`, `.Dockerfile`, python patches.
   - Console components: `index.html`, `blastem.html`, `generate-roms-manifest.py`, `scrape_covers.js`, `main.js`.
   - Game components: `settings-*.ini`, `index.html`.

3. **Update Build Scripts**:
   - Run a Python replacement script to update paths inside the shell scripts (`SCRIPTS_DIR` logic, relative paths to HTML files).

4. **Verify Build**:
   - Ensure `build-blastem-docker.sh` and other build scripts still point to the correct output and input directories.
