# engine-specs 0.6.2: keys in menus, Escape in fullscreen

## 2026-11-17 18:40 UTC — Plan and walkthrough

engine-specs 0.6.2 adds `UiInput.setKeyAliases()` (the keys bound to the pad's buttons work in an
engine app's menus) and makes `createFullscreenToggle()` keep Escape for the pause menu. The
launcher's input (`src/lib/input.service.js`, `createInput()`) is the one every engine app gets as
`host.input`, so the launcher needs 0.6.2 for the aliases to work; the apps call
`setKeyAliases?.()`, so with 0.6.1 nothing broke, the keys just did nothing.

- `package.json`: `@wasm-gaming/engine-specs` `^0.6.2`, lockfile updated. No code change.
- Later in this record: the engines' pins, as each releases with 0.6.2 (BlastEm first:
  wasm-gaming/blastem-wasm#7).

Checks: `npm test` 25 / 25, `vite build`. Chromium with BlastEm's branch build: keyboard A / S in the
pause menu save, open a slot's sheet, close it and return to the game; Escape in fullscreen opens
the pause menu.

Suggested commit: `chore: engine-specs 0.6.2 (the launcher's input takes the apps' key aliases)`
