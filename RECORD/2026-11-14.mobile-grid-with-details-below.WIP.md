# Mobile: a grid of games, details below the one you tap

_2026-11-14_

## Context

Owner, with a phone screenshot of the launcher: "En mobile, pondría el grid de juegos, y al hacer
click en cada uno, que aparezcan sus detalles y acciones debajo". Today, under 760px, the page is the
desktop TV layout squeezed: a tall hero (title, chips, description, Instalar) that takes most of
the screen, the rows scrolling sideways with tiles cut at the edge, and the keyboard/pad hint bar
overlapping the tiles.

## Plan (≤ 760px only; desktop/TV unchanged)

1. **No hero.** The `Hero` is hidden; the page is the top bar and the rows.
2. **Rows become grids.** Each row's `.cards` wraps into a grid (3 columns; 2 below ~360px)
   instead of a sideways strip, so every game is visible without horizontal scrolling. Captions
   keep title + year.
3. **Tap a game → its details open below it**, like the emulators' iOS-6 folder already does: a
   full-width panel inserted after the grid line that holds the tile, with the notch pointing at
   it. The panel is the hero's content — kicker, title, chips (year, engine, Instalado /
   Próximamente), description and the actions (Jugar / Instalar / Quitar datos). Tapping the same
   tile again, or another one, closes / moves it. The first tap no longer launches the game; the
   panel's button does.
4. **Emulators** keep their ROM folder on tap (it already opens below the tile); the folder gets
   the same "grid line" placement.
5. **Hint bar** hidden on touch screens (`pointer: coarse`): it lists keyboard/pad keys and covers
   the last tiles.
6. Keyboard/pad on desktop keep today's behaviour (Enter opens directly).

Implementation notes: the panel is a `<li>` with `grid-column: 1 / -1` rendered inside `.cards`
after the last tile of the tapped tile's line (columns read from the grid's computed
`grid-template-columns`); the hero's markup is reused through a shared component
(`GameDetails.html`) so both stay in sync. `matchMedia('(max-width: 760px)')` decides whether a tap
opens details or launches.

**Verify:** `npm test`; build + preview screenshots at 390×844 (grid; details open on a game, on an
installed game, on a "Próximamente" one; ROM folder on an emulator) and at 1440×900 (unchanged).
