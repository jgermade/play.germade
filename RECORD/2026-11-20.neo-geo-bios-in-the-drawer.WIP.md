# Neo Geo drawer: the BIOS, shown and loadable

**Status: Plan — awaiting approval before any code changes.**

## 2026-11-20 12:25 UTC — Report and plan

Owner's report: in the Neo Geo drawer there is no option to load the BIOS.

Measured on play.germade.dev (headless Chromium, `es`, the owner's `neogeo.zip` and `mslug.zip`):
- Empty drawer: "0 juegos · Añadir ROMs · Suelta aquí tus ROMs…" — nothing says a BIOS is needed.
- `neogeo.zip` alone through the drawer's file input: still "0 juegos", no message on screen. It
  was added (the next import reports "BIOS de AES añadida"), but the drawer never shows whether
  the library has a BIOS. The only way in is to mix it with the ROMs, by its file name; the
  catalog's `bios` entry (`{ file: 'neogeo.zip', label }`) is used by nothing in the drawer.
- Without it, a game fails only at launch ("Falta la BIOS neogeo.zip…").

Plan, `src/views/RomDrawer.html` (+ `src/lib/messages.js`), only for systems whose catalog entry
has `bios` (today Neo Geo):

1. **A BIOS tile** at the end of the grid, after "Añadir ROMs", in the same style:
   - with the BIOS in the library (`entry.bios`): "BIOS · neogeo.zip ✓" — activating it replaces it;
   - without it: "Cargar BIOS" (es) / "Load BIOS" (en), marked as missing.
   It is a normal grid cell, so the pad, the keyboard and the pointer reach it the same way
   (focus count + 1; Enter / A activates).
2. Activating it opens a file picker of its own (`accept=".zip"`, all files on touch devices as
   today) and imports through `library.importFiles(system, [file])`. The result decides the
   message: `bios` set → the existing "BIOS de AES añadida" lines; otherwise "Esto no es la BIOS
   de Neo Geo (neogeo.zip)" and nothing else is reported as added.
3. The empty-drawer text, for a system with a BIOS, adds one line: "Además de los juegos, hace
   falta la BIOS neogeo.zip" while it is missing.
4. Messages in en / es next to the existing `drawer.bios.*`.

Not changed: how the BIOS is stored or found (rom-manager, `NEOGEO/neogeo.zip`), adding it mixed
with ROMs (still works), the launch-time check.

Verify: `make test`; headless Chromium on a local build: the tile says "Cargar BIOS" on an empty
library, loading `neogeo.zip` through it turns it into "BIOS · neogeo.zip ✓" with the message, a
wrong zip is refused, the tile is reachable with the pad (fake pad: right to it, A opens the
picker), and Metal Slug boots after.
