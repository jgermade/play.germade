# Netflix-Style UI Refactor and OPFS Detection

## Topic: Netflix UI Refactor

- **Status:** In Progress
- **Created:** 2026-07-04 21:12

### Objective
- Completely overhaul the launcher UI (`src/pages/index.astro`) to look like a premium, Netflix-style streaming service for games.
- Flatten the Celeste build structure by placing the built game directly in `game/celeste/`.
- Add client-side logic to detect OPFS installation status for each game.

### Proposed Changes

1. **Flatten Celeste Build Path:**
   - Update `scripts/celeste/build-celeste.sh` to move the Emscripten output directly into `public/game/celeste/`.
   - Rename the generated `index.html` to `game.html` during the build so it avoids conflict with Astro's generated `index.html`.
   - Update the UI and iframe inside `src/pages/game/celeste/index.astro` to load `/game/celeste/game.html`.

2. **Launcher UI Overhaul (Netflix Style):**
   - Redesign `src/pages/index.astro`.
   - Implement a **Hero Section** at the top featuring a highlighted game with a large banner and clear actions.
   - Group games into **categories** (e.g., Platformers, Shooters, Sonic Collection) using horizontal scrolling rows.
   - Use dynamic aesthetic features: dark mode, CSS gradients, hover animations (scaling and highlighting).
   - Use AI image generation to create high-quality missing game covers and banners (e.g., Sonic, Quake, Doom, Celeste) and place them in `public/covers/`. Update `src/data/games.ts` with references to these images.

3. **OPFS Installation Check:**
   - Add client-side scripting to the main launcher that accesses `navigator.storage.getDirectory()` to check if specific games are already installed (e.g., checking for `.ContentExists`).
   - Dynamically update the launcher UI to show a direct "Play" button for installed games, bypassing the installer page. Uninstalled games will show "Install" or "Setup".
