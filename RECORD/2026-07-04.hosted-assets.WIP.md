## Hosted Assets for Celeste (Bypass OPFS Picker)

User request summary:
1. Avoid loading game files from the browser's directory picker every time.
2. Allow hosting the assets in the production server (protected by OAuth2) so the user can play anywhere without providing the local files.

Planned changes proposal:
1. **Packaging Script**: Create a script `scripts/package-celeste-assets.sh` that takes the Steam Celeste folder as an argument and packages it into a `public/game/celeste/assets.zip` file.
2. **Dependency Update**: Install `fflate` via `npm install fflate` to allow fast client-side ZIP extraction in the browser.
3. **Astro Injector Script**: Modify `src/pages/game/celeste/index.astro` to:
   - Check if OPFS (Origin Private File System) is already populated.
   - If not, download `/game/celeste/assets.zip` via `fetch()`.
   - Use `fflate` to extract the contents directly into OPFS.
   - Create `.ContentExists` to signal `celeste-wasm` that files are ready.
   - Boot the `celeste-wasm` iframe seamlessly, completely bypassing the directory picker step.
