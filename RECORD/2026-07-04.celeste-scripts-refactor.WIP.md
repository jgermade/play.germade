# Celeste Scripts Refactor and Pre-patching

## Topic: Celeste Scripts Refactor

- **Status:** In Progress
- **Created:** 2026-07-04 18:52

### Objective
- Refactor the Celeste scripts folder structure.
- Add `--patched` flag to `package-celeste-assets.sh` for pre-patching `assets.zip`.

### Proposed Changes
1. **Move scripts:** 
   Move all Celeste-related scripts into a new `scripts/celeste` directory.
   - `scripts/build-celeste-docker.sh` -> `scripts/celeste/build-celeste-docker.sh`
   - `scripts/build-celeste.sh` -> `scripts/celeste/build-celeste.sh`
   - `scripts/package-celeste-assets.sh` -> `scripts/celeste/package-celeste-assets.sh`
   - `scripts/docker` (Celeste docker files) -> `scripts/celeste/docker`

2. **Update `Makefile`:**
   Modify the paths in `Makefile` to reflect the new `scripts/celeste/build-celeste-docker.sh` path.

3. **Update script contents:**
   Modify paths inside the scripts (like `scripts/celeste/build-celeste-docker.sh` pointing to `scripts/celeste/docker/...` and `scripts/celeste/build-celeste.sh`).

4. **Add `--patched` option:**
   Update `scripts/celeste/package-celeste-assets.sh` to accept `--patched` option as its first or second parameter. This option will zip the `assets.zip` pulling Everest files and any extra mods inside the bundle.

### Extension (2026-07-04 20:47)
- **Fix Web Worker Gamepad Crash**: Add a post-build step in `scripts/celeste/build-celeste.sh` to patch the generated `dotnet.native.worker.*.mjs` and `dotnet.native.*.js` files. The patch injects a polyfill for `navigator.getGamepads` (`if(typeof navigator!=="undefined"&&!navigator.getGamepads)navigator.getGamepads=function(){return[]};`) to prevent `TypeError: navigator.getGamepads is not a function` when Emscripten checks for gamepads inside a Web Worker.

### Extension (2026-07-04 20:53)
- **Implement Gamepad Proxy for Web Workers**: Since Emscripten's pthreads run in Web Workers which lack access to `navigator.getGamepads`, we will implement a `SharedArrayBuffer` proxy.
  1. **Main Thread Interceptor**: A script injected into `index.html` during the build process that queries gamepads via `requestAnimationFrame`, serializes their state (axes and buttons) into a `SharedArrayBuffer`, and overrides the `Worker` constructor to pass this buffer to new workers via `postMessage`.
  2. **Worker Decoder**: A script injected into the top of `dotnet.native.worker.*.mjs` that intercepts the `postMessage`, decodes the `SharedArrayBuffer`, and exposes a polyfilled `navigator.getGamepads()` function for SDL to consume.
  3. **Build Script Update**: We will write a Node.js script `scripts/celeste/patch-gamepad-proxy.mjs` to apply these code injections during `build-celeste.sh`.
